## 2025-01-16 - Prevent TOCTOU vulnerabilities when writing files
**Vulnerability:** `SysctlJournal.swift` wrote temporary files with default permissions before restricting them to 0600.
**Learning:** `Data.write(to:)` creates files using the process's default umask, causing a brief window of exposure before `setAttributes` is applied. While temporarily changing `umask` can fix this, `umask` modifies a global process state and is thread-unsafe, which can cause concurrent tasks to incorrectly create restricted files.
**Prevention:** To safely prevent TOCTOU vulnerabilities without global side effects, use POSIX `open()` with flags `O_CREAT | O_WRONLY | O_EXCL | O_CLOEXEC` and the desired mode (e.g. `S_IRUSR | S_IWUSR`), then wrap the file descriptor in a `FileHandle` with `closeOnDealloc: true`.
